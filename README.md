# AvatarWorks Digital Agency Website

A modern digital agency website built with **Next.js** and **MongoDB**, designed to showcase services, generate client enquiries, and provide a fast, responsive user experience.

Unlike a typical agency template, this project was designed and developed with custom layouts, reusable components, and interactive UI elements to create a unique brand identity.

## Live Demo

https://avataworks.com

## Project Overview

The goal of this project was to build a professional agency website that not only presents the company's services but also serves as a lead generation platform.

The application includes a custom frontend, backend data handling, and an enquiry system for capturing information submitted by potential clients.

One of the development goals was to reduce manual content management. To achieve this, I built a workflow that converts structured JSON data into MongoDB records through API requests, allowing content to be populated programmatically instead of being entered manually.

## Technical Highlights

### API-Based Data Seeding

Instead of manually creating database records, I implemented an API workflow that imports structured JSON data directly into MongoDB. This approach makes future updates easier and significantly reduces repetitive manual work.

### Component-Based Architecture

The interface was built using reusable components to keep the codebase maintainable and scalable as new pages and services are added.

### Responsive Design

Every page was designed to provide a consistent experience across desktop, tablet and mobile devices.

## Challenges

One challenge was creating a website that felt custom without depending on pre-built templates.

The project was structured around reusable components and modular layouts, making it easier to maintain while preserving a unique visual identity.

Another challenge was simplifying content management. Rather than manually inserting records into the database, I created an API-driven import process that automatically populated MongoDB using structured JSON data.
